## Overview

The CoW Fee Module is deployed across 11 networks, supporting both mainnet and testnet environments. This page provides deployment addresses, transaction hashes, and network-specific information for each deployment.

<Note>
  All deployments use the same contract code but with network-specific configuration parameters.
</Note>

## Verifying Deployments

You can verify any deployment using Cast:

```bash
# Check if contract exists
cast code <module-address> --rpc-url <rpc-url>

# Read settlement address (should be 0x9008D19f58AAbD9eD0D60971565AA8510560ab41)
cast call <module-address> "settlement()" --rpc-url <rpc-url>

# Check all constructor parameters
cast call <module-address> "safe()" --rpc-url <rpc-url>
cast call <module-address> "wrappedNativeToken()" --rpc-url <rpc-url>
cast call <module-address> "keeper()" --rpc-url <rpc-url>
cast call <module-address> "appData()" --rpc-url <rpc-url>
cast call <module-address> "receiver()" --rpc-url <rpc-url>
cast call <module-address> "minOut()" --rpc-url <rpc-url>
```

## Comparing Deployments

If you deploy a new instance and want to compare parameters with an existing deployment:

```bash
yarn ts-node compare-deployments.ts \
  --network <network-name> \
  <new-module-address>
```

This script compares the new deployment's parameters with the existing deployment on that network.

## Common Configuration

All deployments share:

- **Settlement Contract**: `0x9008D19f58AAbD9eD0D60971565AA8510560ab41` (CoW Protocol Settlement)
- **Contract Version**: Same source code across all networks
- **License**: GPL-3.0-or-later

Network-specific:

- **Wrapped Native Token**: Varies by network (WETH, WXDAI, WAVAX, etc.)
- **Target Safe**: Network-specific Safe addresses
- **Keeper**: Network-specific keeper accounts
- **Receiver**: Network-specific fee recipients
- **Min Out**: Network-specific minimum output thresholds
